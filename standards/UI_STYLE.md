# UI・CSSの既定ガイド

この文書は画面の見た目を完全に固定するものではありません。既存デザイン・ユーザー指定が優先です。新規React/ViteアプリのCSS出発点は [templates/web-react/src/styles.css](../templates/web-react/src/styles.css) にあります。独立したTemplate Repositoryへの分離は今後の作業であり、既存アプリには強制適用しません。

- シンプルで読みやすいフラットなUIを基本にし、不要なグラデーション・装飾を増やさない。
- ヘッダーやフッターの区切り線は、既存サイトのようにコンテンツ幅に揃える方式を既定候補とする。
- PC/スマホの要件はユーザー指定に従う。勝手に「スマホ必須」や「PC専用」を決めつけない。
- レスポンシブ対応時は情報を無理に詰め込まず、横スクロール・タップ領域を検証する。
- 表示文言、ボタンの位置、余白、既存コンポーネントは変更対象外なら維持する。
- CSS変数による色・余白・タイポグラフィの管理を推奨するが、既存の設計手法を強制変更しない。
- 開発中の状態・今後の予定・実装メモをアプリ画面へ追加しない。
- アクセシビリティ（ラベル、キーボード操作、可読性）を機能に応じて配慮する。
