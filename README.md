# naoiw/.github

naoiw 配下のリポジトリで利用する、共通のコミュニティファイル・開発規約・再利用可能ワークフローの管理リポジトリです。

## 適用範囲

- GitHub が標準で継承する Issue / Pull Request テンプレート、CONTRIBUTING.md などは、各リポジトリに同種の設定がない場合に利用されます。
- `standards/` や `templates/` の開発・AI指示は、GitHub によって他リポジトリへ自動配布されません。各リポジトリにブリッジ用の指示ファイルを配置するか、AIに共通規約を明示して参照させてください。
- `.github/workflows/` の再利用可能ワークフローは、各リポジトリから明示的に呼び出します。
- 明示的な指示とリポジトリ固有の設計・ライセンスは共通の推奨値より優先します。

開発ガイドは `CONTRIBUTING.md` と `standards/` を参照してください。
